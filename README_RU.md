# SVG Recompile — GitHub Pages

Статическое веб-приложение для замены встроенных изображений в SVG. Работает целиком в браузере и подходит для публикации на GitHub Pages: PHP, сервер, база данных и сборка не требуются.

## Публикация

1. Создайте GitHub-репозиторий и загрузите в его корень `index.html` и папку `assets/`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, нужную ветку и папку **/(root)**, затем нажмите **Save**.
4. Дождитесь публикации и откройте адрес Pages, показанный GitHub.

Можно также загрузить файлы в существующий репозиторий и выбрать папку, в которой лежит `index.html`, как источник Pages.

## Использование

1. Выберите исходный `.svg` и нажмите **Разобрать SVG**.
2. Для нужных `<image>` выберите файлы-замены.
3. Нажмите **Собрать и скачать SVG**.

Поддерживаются PNG, JPG/JPEG, WEBP, GIF, SVG, BMP и ICO. Внешние ссылки и изображения, которые не встроены как base64 data URI, показываются в списке, но остаются без изменений. Обработка происходит на устройстве пользователя; исходный SVG и замены не отправляются на GitHub Pages или сторонний сервер.

## Файлы

- `index.html` — интерфейс и логика обработки.
- `assets/style.css` — оформление.

Приложение не использует PHP-файлы из серверного варианта: GitHub Pages исполняет статические HTML, CSS и JavaScript, но не PHP.
